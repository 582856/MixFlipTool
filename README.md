# MixFlipTool

@酷安：[KuaKuaC](https://www.coolapk.com/u/9521915)

免root一键配置Mix Flip外屏 添加和使用任意应用 + 系统应用恢复默认样式

此 fork 支持 Root 或 Shizuku 授权，使用 miuix 界面管理外屏应用，并为 Mix Flip 2 增加实验性的外屏音乐显示。

## 此 fork 的功能与安装

- [下载最新版本](https://github.com/582856/MixFlipTool/releases/latest)。更新此 fork 可直接覆盖安装并保留设置；从不同签名的原版迁移时需先卸载原版。
- 首次打开时，在同一个权限页面完成 Root 或 Shizuku 授权、应用列表授权；权限有效时不再显示引导。
- 主页提供“外屏应用解锁”“外屏音乐显示”和“检查更新”。应用列表支持缓存、搜索、显示系统应用和下拉刷新。
- “外屏音乐显示”依赖 LSPosed/Vector。启用模块并勾选“系统框架（system）”和“系统界面（com.android.systemui）”后重启；外屏应用解锁仍沿用 Root/Shizuku，无需启用模块。
- 外屏音乐的独立亮息屏适配目前仅针对 Mix Flip 2（bixi，Android SDK 37）；其他机型和系统版本未验证。展开手机并播放音乐后生效，合盖恢复系统外屏。
- 外屏双击切换亮屏和息屏，亮屏约 15 秒无操作后自动息屏。音乐暂停保留信息，关闭播放器后退出；内屏解锁不会自动点亮外屏。
- 分别设置亮屏、息屏时的封面、律动、专辑名、歌名、歌手、当前歌词、下一句歌词和整组播放控制按钮。已适配网易云音乐、小米音乐与波点音乐；歌词和封面可用性取决于播放器提供的数据。
- 进入主页时自动检查 GitHub 正式版本，成功后 24 小时内不重复自动检查；也可手动检查。有新版时使用居中的 miuix 风格弹窗显示更新内容并前往下载。

外屏音乐显示仍为实验功能。已知BUG：未知操作导致内屏卡顿。

下方保留上游功能说明与操作参考，当前入口以本节为准。

## 操作步骤

### 授权（安装后只需执行一次）

相关功能依赖于DUMP权限，因此在安装后，需要向应用进行一次授权，方法有3种：

1. **Root 自动授权（此 fork 新增）**：已 Root 的手机直接点击 MixFlipTool，在 Magisk / KernelSU / APatch 等 Root 管理器的弹窗中允许授权。授权在后台执行，最多等待 60 秒，成功后继续一键配置；没有 Root 或拒绝授权时，仍可使用下面的 ADB / Shizuku 方式。多用户环境下只为当前用户授予 DUMP 权限。

2. 通过ADB授权，手机开启USB调试和USB调试（安全设置）后，连接电脑，命令行里执行

```
adb shell pm grant com.parallelc.mixfliptool android.permission.DUMP 
```

3. 通过[Shizuku](https://github.com/RikkaApps/Shizuku)授权，启动Shizuku后，点击MixFlipTool，会出现弹窗，选择`始终允许`

<img src="/imgs/shizuku.jpg" width="33%" alt="Shizuku">

### 一键配置

点击MixFlipTool，就会进行配置，配置成功会有提示，如果出现获取应用信息的弹窗，选择 允许（第二行或第三行）

<p>
   <img src="/imgs/read_app_list.jpg" width="30%" alt="获取应用信息">
   <img src="/imgs/one_click_config.jpg" width="30%" alt="配置成功">
</p>

注意：

- 一键配置仅会对当前已安装的应用生效，且手机重启后就会失效，因此每次重启或安装新应用后，需要重新执行一键配置


- 一键配置之前已经打开的应用，需要关闭后才能在外屏使用，因此建议一键配置成功后，执行一下后台一键清理

### 刷新设置里的外屏应用列表

一键配置成功后，需要重启`外屏桌面`，才能使`设置-外屏-外屏应用`里出现最新配置的应用，重启方法：

进入`设置-应用设置`，右上角三个点选择`显示所有应用`，找到`外屏桌面`，点击`结束运行`

### 自定义应用在外屏的缩放比例

注意：

- 此功能并不适用于外屏全屏显示的应用，如`天气`


- 对`时钟`进行缩放比例设置，会导致闹钟在锁屏状态下不响

在内屏长按MixFlipTool，会出现`缩放比例设置`的菜单，打开后会显示当前的设置

默认对系统应用进行了一些设置，用于恢复系统应用在外屏的默认样式，可点击应用进行调整设置，设置完成后需要再回到桌面点击MixFlipTool，进行一键配置

## 常见问题

### 外屏设置的应用列表不全

- 尝试重新执行`一键配置`和`刷新设置里的外屏应用列表`


- 个别应用确实无法出现在外屏应用列表里，如`Google`，可通过安装一个第三方启动器应用，间接在外屏启动

### 对米家、网易云设置缩放比例，无法恢复默认样式

米家、网易云的外屏样式，不是通过检测缩放比例来展示的，而是`外屏桌面`专门调用了它们特殊的启动页

如果不想进入它们的外屏启动页，可使用旧版本或通过第三方启动器应用启动
